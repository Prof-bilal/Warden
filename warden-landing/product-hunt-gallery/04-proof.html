It blocks attacks by design, not by accident.

Six hard invariants, verified by the test suite — including escape tests that confirm the sandbox actually prevents the access it claims to block.

Fail-closed by defaultRefuses to start without a valid sandbox backend. No backend, no run.
Deny-by-default filesystemOnly explicitly granted paths are visible. Everything else is invisible.
Network at kernel levelEgress proxy blocks every hostname not in the policy. DNS after allowlist.
Environment filteringOnly env.allow names forwarded. Empty allowlist = empty environment.
Fail-closed on every platformLinux, macOS, Windows, Docker — each requires its primitives or the run is refused.
Kernel resource limitsWall-clock timeout, memory RSS sampling, kill-on-close via Job Objects.
Verified on Linux (Arch x86_64): 7 escape tests pass — read grants accessible, unlisted paths invisible, writes outside grants denied, fail-closed without bwrap.
Code-complete, verification pending: macOS (Seatbelt) and Windows (AppContainer + WFP + ETW) — unit tests pass; real-machine escape tests require their platforms.
