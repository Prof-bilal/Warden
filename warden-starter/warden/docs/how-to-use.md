# How to use Warden

This page has moved into the [Quickstart](quickstart.md), which covers the same steps in one tutorial:

1. Install and check the machine with `warden doctor` ([Install](install.md)).
2. Write a small policy that grants only what the program needs.
3. Run the program with `warden run --policy policy.yaml`.
4. Check blocked and allowed accesses with `warden logs`.

For the policy fields, see the [Schema reference](schema.md). For the full list of commands, see the [CLI reference](cli.md).
